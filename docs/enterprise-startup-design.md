# Verified corpus API startup

The authenticated statement endpoint already accepts an immutable source-built index. The existing corpus and model launchers do not construct that index; consumers need undocumented custom composition. This change supplies an installed startup path and connects the existing model launcher without changing either HTTP response contract.

1. Package the lexical `create_corpus_app` and `python -m nvidia_rag.serving`, with console entry `nvidia-rag-serve-corpus`. Keep the example's function and loopback-only argument contract. The installed CLI defaults to loopback and permits an explicit container bind. Resolve the environment token before any input I/O, fitting, extraction or server imports. Keep threshold explicit, concurrency 16, keep-alive five seconds, optional docs and disabled access/proxy/server headers.
2. Add `load_statement_snapshot` in `statement_startup.py`. Inputs are an absolute local source registry, source directory and independent fiscal declaration file. Its frozen `StatementSnapshot` exposes `.index` and `.verify_unchanged()`. Registry schema 1/2 source validation is reused without changing corpus recipes. All declarations bind the exact registry byte hash, exact document ID and pinned PDF hash. Annual identity is an explicit integer fiscal year and null quarter; it is never inferred from a filename, URL or calendar year.
3. Declaration schema is exactly `{schema_version: 1, source_registry_sha256, reports}`. Each report contains exactly `document_id`, `pdf_sha256`, `fiscal_year`, `fiscal_quarter`, `reviewed_by`, `source_locator`. Reject duplicate members, constants, unknown fields, noncanonical text, booleans as integers, duplicate reports, malformed hashes, unregistered sources, quarterly conflicts and files over 1 MiB. It is an operator declaration, not human gold or legal/financial validation.
4. Registered PDF basenames stay inside the explicit source root; absolute paths must not hide symlink/junction components. Existing parser limits of 128 reports, 256 MB per PDF and 2048 pages remain. The declaration file may describe a larger verified corpus, but a document scope builds only its declared selected reports, with no global fallback or access to unselected PDFs. Unknown scope and an empty selected declaration set fail startup. Expected source records supplied by the corpus factory must exactly match the current registry.
5. The snapshot retains identities of registry/declarations/selected PDF inputs. Model startup can additionally bind `corpus_manifest` and `chunks_path`: exact chunk hash, registered document identity/hash/filename/label/URL and actual chunk counts must agree. This opt-in binding does not promote the legacy model corpus into the stricter local-recipe format. Recheck all retained inputs after construction and again immediately before listening; the corpus factory additionally retains artifact hashes and completion markers. Explicitly invalid requested configuration aborts startup; absent optional configuration preserves authenticated statement 503.
6. Do not refresh indexes or inspect paths on HTTP requests. Statement requests keep source-candidate/refuse/clarify/unsupported outcomes and never invoke retrieval or generation. Existing query behavior remains unchanged. Native synthetic sources, installed-wheel HTTP and read-only nonroot container acceptance are separate from exposed original-source replay and financial correctness.

The implementation follows the user's existing authorization to continue the complete RAG goal. The independent startup audit confirmed this composition gap at `bf7e926`; no additional product preference is required to implement the previously recorded enterprise integration step.
